# PRD — SENAI Plano Inteligente V3

## Objetivo
Criar planos de ensino por competências para uso pessoal, sem API externa, usando o ChatGPT como camada inteligente e a aplicação como camada de organização, cálculo, edição, auditoria e exportação.

## Fluxo principal
Plano de Curso → leitura local → seleção da UC → carga horária → cálculo de aulas → pedido estruturado para Ana → importação JSON → auditoria → Word/PDF.

## Regra de rastreabilidade
Cada aula deve ligar: Capacidade → Conhecimento → Estratégia → Recurso → Critério → Instrumento.

## Regras
- Fechar exatamente a carga horária da UC.
- Não criar capacidades que não estejam previstas no Plano de Curso quando o plano inteligente vier da Ana.
- Capacidades socioemocionais devem ser coerentes com a atividade e observáveis.
- Critérios precisam ser mensuráveis/observáveis.
- Instrumentos precisam registrar a evidência de desempenho.
- Estratégias devem trazer passo a passo real de ensino.
